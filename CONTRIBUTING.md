# Вклад в проект

Спасибо, что хотите помочь!

## Самое полезное прямо сейчас

1. **Сообщить, что конвертер что-то сломал.** Приложите исходный файл из
   `.claude/` и результат из `.qwen/` — этого достаточно, чтобы воспроизвести.
2. **Добавить провайдера с бесплатным тарифом** в `qwenkit/providers.py`
   (см. ниже, это ~20 строк).
3. **Прислать команду или субагента** для `qwenkit pack` — если пользуетесь
   своими заготовками и они удачные.

## Запуск тестов

```bash
pip install -r requirements.txt
python3 tests/test_qwenkit.py       # pytest не нужен
```

Тесты не обращаются к сети, кроме блока `[14] CLI запускается`, который дёргает
`qwenkit providers` (он запрашивает живой каталог OpenRouter и корректно
деградирует без сети).

**Перед коммитом обязательно:**

```bash
python3 tests/test_qwenkit.py     # ожидаем: провалено: 0
python3 -m py_compile qwenkit/*.py
```

`pyyaml` должен быть установлен, иначе половина проверок провалится с
сообщением «не установлен PyYAML» — это не баг конвертера, а отсутствие
зависимости в вашем окружении.

## Если qwen-code поменял схему

Все таблицы соответствий живут в одном файле — `qwenkit/maps.py`. Обновлять надо
его, а не логику конвертера.

Проверить канонические имена инструментов и поля совместимости с Claude Code:

```bash
curl -s https://raw.githubusercontent.com/QwenLM/qwen-code/main/packages/core/src/tools/tool-names.ts \
  | grep -oE "': *'[a-z_]+'"
```

Пошаговая инструкция и перечень первоисточников — в [`SOURCES.md`](SOURCES.md).

**Обязательно добавьте тест** на каждое новое соответствие в
`tests/test_qwenkit.py`. Без теста правило считается несуществующим: его
сломают при следующем рефакторинге.

## Добавление провайдера

В `qwenkit/providers.py`:

```python
_reg(Provider(
    key="myprovider",                              # значение для --provider
    title="Название",
    base_url="https://api.example.com/v1",         # корень OpenAI-совместимого API
    env_key="MYPROVIDER_API_KEY",
    signup="https://example.com/keys",
    free="что именно бесплатно и какие лимиты",
    models=["model-a", "model-b"],                 # проверенные id
    models_url="https://api.example.com/v1/models", # если каталог читается без ключа
    notes="подводные камни",
))
```

и добавьте `key` в `FREE_ORDER` или `PAID_ORDER`.

**Не добавляйте провайдера, пока не убедитесь, что он поддерживает tool-calling.**
Qwen Code — агент: без function calling модель не сможет вызывать инструменты,
и конфиг окажется бесполезным. Проверка:

```bash
qwenkit probe --provider myprovider --model model-a
```

`probe` шлёт запрос с объявленным инструментом и смотрит, вернулись ли `tool_calls`.

## Стиль

- Русский язык в сообщениях пользователю и комментариях, английский — в
  идентификаторах и в промптах там, где это уместно.
- Конвертер **никогда не перезаписывает файлы молча**: существующее уезжает в
  бэкап, спорное — в предупреждения или в `MIGRATION_TODO.md`.
  Новое правило должно следовать тому же принципу.
- Предупреждение должно объяснять, **что делать**, а не только констатировать факт.

## Чего делать не надо

- Не храните ключи API в `settings.json` и тем более в репозитории.
  `qwenkit` намеренно ссылается на env-переменные через `envKey`.
- Не копируйте в репозиторий документацию qwen-code. Ссылайтесь на неё —
  как сделано в `SOURCES.md`.
